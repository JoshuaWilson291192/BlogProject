# Blog Project 🚀

## Overview 🌟
This project aims to build a fully functional blog using **HTML, CSS, JavaScript, C#, and .NET**. The blog will feature:

- A homepage with a list of posts
- Individual post pages
- A comment section
- An admin panel for managing posts

---

## Features ⭐

- **Homepage**: Displays a list of blog posts with titles, excerpts, and publication dates.
- **Post Page**: Shows the full content of a blog post, along with comments.
- **Comment Section**: Allows users to leave comments on posts.
- **Admin Panel**: Provides functionality to add, edit, and delete blog posts, secured with user authentication.
- **Categories/Tags**: Organizes posts into categories or tags for easy navigation.

---

## Technologies Used 🛠️

- **Frontend**: HTML, CSS (with Bootstrap), JavaScript 💻  
- **Backend**: C#, ASP.NET Core 🖥️  
- **Database**: SQL Server with Entity Framework Core 🗄️
